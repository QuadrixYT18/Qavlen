# Security Policy

## Supported versions

Security fixes are made for the latest release.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues. Use [GitHub's private vulnerability reporting](https://github.com/QuadrixYT18/Qavlen/security/advisories/new) instead.

Include the affected version or commit, the impact, and a minimal reproduction. Do not include real credentials or personal data. You will receive a response as soon as possible; please allow time for a fix before disclosing details.

Areas of particular interest are injection through placeholders (MiniMessage, SQL), plugin message spoofing, unsafe deserialization and resource exhaustion in configuration parsing.
